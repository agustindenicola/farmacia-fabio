# Farmacia Fabio

Web para una farmacia de barrio: catálogo, promociones, turnos y consultas online, con un panel simple para que el dueño la mantenga actualizada.

> Proyecto de **DGLab** · Demo

## Qué incluye

- **Sitio público** (`index.html`): promociones destacadas, categorías, horarios, ubicación y consejos de salud.
- **Panel de administración** (`admin.html`): turnos del mes, consultas recibidas y edición de contenido.

## Tecnología

Sitio estático en HTML, CSS y JavaScript. Se puede publicar en cualquier hosting estático (Netlify, GitHub Pages).

## Ver localmente

Abrir `index.html` en el navegador.
